コーヒーに必要な道具

コーヒーを淹れる道具には、最初に揃えたい基本の道具から、 抽出方法に合わせて選ぶ専用器具までさまざまな種類があります。 それぞれの役割と特徴を知り、自分の飲み方に合った道具を選びましょう。

最初からすべて揃える必要はありません。まずは使いたい抽出方法を決め、 必要な道具から少しずつ揃えていくと始めやすくなります。

OVERVIEW

このページで学べること

コーヒーの道具は、豆を挽くもの、お湯を注ぐもの、抽出するもの、量や時間を測るものなど、 役割によって分けられます。どの道具が必要かは、ハンドドリップ、フレンチプレス、 エスプレッソなど、選ぶ抽出方法によって変わります。

選び方と手入れ

予算や使い方に合わせた選び方と、清潔に保つ方法を知る。

01 / BASIC TOOLS

基本の道具と役割

道具を選ぶ前に、それぞれが何のために使われるのかを知っておきましょう。 すべての道具が必須というわけではありませんが、量を測ったり、抽出方法に合った器具を使ったりすると、 同じ条件でコーヒーを淹れやすくなります。

豆を挽く

コーヒーミル

焙煎したコーヒー豆を粉にする道具です。手動式と電動式があり、 挽き目を調整できる範囲や、粒の揃いやすさ、手入れの方法は製品によって異なります。

粉の状態で購入すれば、ミルを使わずにコーヒーを淹れることもできます。

粉を入れて抽出する

ドリッパー

ペーパードリップなどで、コーヒー粉にお湯を通すための器具です。 形状や穴の構造によってお湯の流れ方が変わるため、フィルターや注ぎ方との組み合わせも大切です。

粉を受け止める

フィルター

コーヒー粉と抽出液を分けるための道具です。 ペーパー、布、金属などの種類があり、粉や油分が抽出液にどの程度含まれるかなどに違いが出ます。

お湯を注ぐ

ケトル・ポット

お湯を温めたり、抽出器具に注いだりするために使います。 ハンドドリップでは、注ぐ量や位置を調整しやすい細口のケトルが便利です。

使用する熱源や温度調整機能の有無も確認しましょう。

量を測る

スケール

コーヒー粉やお湯の量を測るためのはかりです。 分量を揃えやすくなるため、前回と同じ条件で淹れたり、味の違いを比較したりするときに役立ちます。

時間を測る

タイマー

抽出時間を確認するために使います。 専用のタイマーがなくても、手元の時計やスマートフォンなどで代用できます。 同じ時間を目安にすると、抽出条件を比較しやすくなります。

抽出液を受ける

サーバー・マグカップ

抽出したコーヒーを受けるための容器です。 一度に複数人分を淹れるならサーバー、1杯分を直接淹れるならマグカップなど、 作る量や使い方に合わせて選べます。

豆を挽くところから始めたい場合はミルが必要ですが、粉のコーヒーを使うなら必須ではありません。 自分がどこまで準備したいかを考えて、必要な道具を選びましょう。

02 / BREWING TOOLS

抽出器具の種類

コーヒーの抽出器具にはさまざまな種類があります。 それぞれ仕組みや準備する道具が異なるため、使いやすさや飲みたいコーヒーに合わせて選びましょう。

ペーパードリップ

ドリッパーにペーパーフィルターをセットし、コーヒー粉にお湯を注いで抽出する方法です。 ドリッパー、対応するフィルター、お湯を注ぐケトルなどを使います。 粉の量や挽き目、お湯の注ぎ方を調整して、味の違いを試しやすい方法です。

フレンチプレス

コーヒー粉とお湯を容器の中で一定時間浸し、金属製フィルターを押し下げて抽出する器具です。 ペーパーフィルターとは異なり、コーヒーの油分や細かな粉が飲み物に残ることがあります。 粉の量、お湯の量、浸す時間を揃えると比較しやすくなります。

エスプレッソマシン

圧力を利用してコーヒーを抽出するための機器です。 エスプレッソを作るには、マシンに加えて、機種に合った挽き目を設定できるミルなどが必要になる場合があります。 ミルの調整や機器の清掃など、ほかの抽出方法とは異なる準備も必要です。

サイフォン

加熱による水蒸気の圧力差を利用してお湯を移動させ、コーヒー粉とお湯を接触させて抽出する器具です。 ガラス製の部品や加熱器具などを使用するため、製品の説明書を確認し、安全に取り扱うことが大切です。

ネルドリップ

布製のフィルターを使ってコーヒーを抽出する方法です。 布の状態や管理方法によって抽出の様子が変わります。 使用後は粉を取り除き、製品や使い方に合った方法で洗浄・保管する必要があります。

エアロプレス

専用の筒状の器具にコーヒー粉とお湯を入れ、押し出す力を使って抽出する方法です。 ペーパーフィルターなどを使用するタイプがあり、手順や挽き目はレシピによって異なります。 比較的コンパクトな器具を探している人にも選択肢のひとつです。

抽出方法 主な道具 選ぶときのポイント
ペーパードリップ ドリッパー、ペーパー、ケトル フィルターの形、注ぎやすさ、洗いやすさ
フレンチプレス プレス本体、計量用の道具 容量、分解・洗浄のしやすさ
エスプレッソ マシン、必要に応じて専用ミル 設置場所、調整機能、手入れの手順
サイフォン サイフォン本体、加熱器具 安全性、部品の扱いやすさ、洗浄方法
ネルドリップ ネルフィルター、対応する器具 使用後の管理、保管方法、手入れの手間
エアロプレス 本体、対応フィルター 容量、使用するフィルター、レシピ
器具によって必要な道具や手順は異なります。 購入前に付属品と対応する消耗品を確認し、使用時はメーカーの説明書を優先してください。

03 / HOW TO CHOOSE

道具の選び方

道具選びで大切なのは、価格や機能の多さだけで判断せず、 自分がどのようにコーヒーを楽しみたいかを考えることです。 初めてなら、使い方が分かりやすく、手入れしやすいものから検討してみましょう。

何杯分淹れるか

1杯分が中心なのか、家族や来客の分も淹れるのかによって、 適した容量や一度に扱える粉の量が変わります。

どの抽出方法を使うか

ドリップ、浸漬式、エスプレッソなど、使いたい方法を先に決めると、 必要な道具を絞り込みやすくなります。

どこに置くか

キッチンのスペースや収納場所も考慮しましょう。 電動器具を選ぶ場合は、電源や設置面積も確認します。

手入れにかけられる時間

分解して洗う部品が多い器具や、使用後の管理が必要な器具もあります。 毎日無理なく使えるかを考えて選びましょう。

手動ミルと電動ミル

手動ミルは電源を必要としない製品が多く、少量ずつ挽きたい場合などに選択肢になります。 一方、電動ミルはスイッチ操作で豆を挽けるため、手で回す作業を減らしたい場合に便利です。 粒度の調整幅や均一性は製品ごとに違うため、使う抽出方法に対応しているかを確認しましょう。

予算と使いやすさ

高機能な道具が、すべての人にとって必要とは限りません。 まずは予算を決め、使用頻度、片付けやすさ、消耗品の入手しやすさなどを比較してみましょう。 必要性が分かってから、道具を買い足す方法もあります。

道具の組み合わせに迷ったら、作りたいコーヒーの種類を先に決めましょう。 その抽出方法に必要なものだけを揃えると、購入する道具を整理しやすくなります。

04 / MAINTENANCE

道具の手入れ

コーヒーの粉や油分、水分が器具に残ると、次に淹れるコーヒーの風味や器具の状態に影響することがあります。 使用後は、各器具の説明書に従って洗浄・乾燥・保管しましょう。

コーヒーミル

内部に粉や油分が残ることがあります。 使用頻度に応じて清掃し、分解できる範囲や清掃方法はメーカーの説明書で確認してください。 水洗いできない部品もあるため、濡らしてよいかを事前に確認することが大切です。

ドリッパー・サーバー

使用後はコーヒー粉を捨て、対応する方法で洗浄します。 洗剤を使う場合は十分にすすぎ、保管する前に水分を切りましょう。 素材によって耐熱性や取り扱い方法が異なるため、製品の表示を確認してください。

フレンチプレス

使用後は粉を取り除き、フィルターやプランジャーなどの部品を洗浄します。 細かな粉が網目に残ることがあるため、部品の構造に合わせて丁寧に洗いましょう。 分解できる範囲は製品によって異なります。

エスプレッソマシン

抽出口やフィルターバスケットなど、使用後に清掃が必要な部分があります。 水垢の除去や内部洗浄の方法・頻度は機種や水質によって異なるため、 メーカーが指定する手順を確認してください。

ネルフィルター

使用後は粉を取り除き、フィルターの説明書や適切な管理方法に従って洗浄・保管します。 布を乾燥させる方法や保管方法は製品・運用によって異なるため、 一律の方法で管理せず、使用する器具に合った手順を確認しましょう。

電気を使う器具や加熱器具は、電源を切る・冷ますなどの安全手順を守ってから手入れしてください。 本体を水に浸けてよいかどうかも、必ず説明書で確認しましょう。

05 / STARTER SET

最初に揃える道具

初めてコーヒーを淹れるなら、最初から多くの道具を購入する必要はありません。 どの抽出方法で始めるかによって、必要なものを選びましょう。

ペーパードリップから始める場合

  1. ドリッパーと対応するペーパーフィルター
    コーヒー粉を入れて抽出するために必要です。サイズや形状が合う組み合わせを選びます。
  2. コーヒー豆または挽いたコーヒー粉
    豆から挽く場合はミルも用意します。粉で始めるならミルは後から検討できます。
  3. お湯を沸かす道具と注ぐためのケトル
    使用する抽出方法や自宅の設備に合わせて選びます。ハンドドリップでは注ぎやすさも確認しましょう。
  4. マグカップまたはサーバー
    抽出したコーヒーを受ける容器です。淹れる量に合った容量を選びます。
  5. 必要に応じてスケールやタイマー
    粉とお湯の量、抽出時間を揃えたいときに役立ちます。最初は手元の時計などで代用することもできます。

フレンチプレスから始める場合

フレンチプレス本体、コーヒー豆または粉、お湯を用意します。 豆から挽く場合はミルも必要です。分量や浸漬時間を揃えたい場合は、 スケールやタイマーを追加すると比較しやすくなります。

購入前に確認したいこと

  • 必要なフィルターや消耗品を継続して購入できるか。
  • 使用するカップやサーバーに器具のサイズが合っているか。
  • 保管場所や洗浄場所を確保できるか。
  • 使いたい抽出方法に対応した挽き目を、手持ちのミルで用意できるか。
道具を揃える目的は、数を増やすことではなく、自分が続けやすい方法でコーヒーを楽しむことです。 まずはひとつの抽出方法を試し、必要を感じた道具から追加していきましょう。
