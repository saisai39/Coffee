コーヒー豆を知る

コーヒーの味や香りは、使う豆によって大きく変わります。品種、産地、精製方法、焙煎度など、豆の個性を決める要素を知ることで、自分の好みに合うコーヒーを選びやすくなります。

このページでは、コーヒー豆そのものの特徴と選び方を学びます。抽出器具や具体的な淹れ方については、Step 1・Step 2で扱います。

コーヒー豆の基本から学ぼう

コーヒー豆を選ぶとき、商品名やパッケージだけで判断する必要はありません。豆の種類や育った場所、加工方法、焙煎の度合いを少しずつ知っていけば、味の違いを理解する手がかりになります。まずは、次の項目から見ていきましょう。

01 / BASICS

コーヒー豆とは？

コーヒー豆は、コーヒーノキという植物になる果実の種子です。果実は「コーヒーチェリー」と呼ばれ、収穫後に果肉などを取り除き、乾燥や選別などの工程を経て生豆になります。その生豆を焙煎することで、私たちがよく目にする茶色いコーヒー豆になります。

生豆は、焙煎前の緑がかった色をした豆です。焙煎によって色や香り、味わいが変化します。つまり、コーヒーの個性は、植物としての特徴だけでなく、収穫後の加工や焙煎によっても作られます。

生豆

焙煎する前の豆。産地や品種、精製方法などの特徴を持っています。

焙煎豆

生豆に熱を加えたもの。焙煎の度合いによって香りや苦味などが変化します。

「豆の種類」「産地」「精製方法」「焙煎度」は、それぞれ別の要素です。例えば、同じ産地の豆でも、精製方法や焙煎度が違えば味わいが変わることがあります。
02 / VARIETIES

豆の品種を知る

コーヒーにはさまざまな種類や品種があります。世界で広く流通している代表的なものとして、アラビカ種とカネフォラ種（ロブスタとして知られるもの）があります。それぞれ特徴が異なるため、コーヒーの味わいや商品づくりにも影響します。

アラビカ種

スペシャルティコーヒーなどでも広く使われる種類です。香りや風味の多様さが特徴で、産地や品種による違いを楽しみやすい豆です。

カネフォラ種（ロブスタ）

アラビカ種とは異なる特徴を持ち、比較的力強い風味や苦味が感じられることがあります。インスタントコーヒーやエスプレッソ用のブレンドなどにも利用されます。

品種だけで味が決まるわけではない

同じ種類の豆でも、育った環境、収穫後の精製方法、焙煎度などによって味わいは変わります。品種名だけで好みの味を完全に判断するのではなく、ほかの情報と合わせて見ることが大切です。

03 / ORIGIN

産地による違い

コーヒー豆の味わいには、栽培される地域の気候、標高、土壌、栽培環境などが関係します。産地は豆の個性を知るための手がかりですが、国や地域だけで味を一律に決められるわけではありません。

中南米

ブラジルやコロンビアなど、コーヒーの主要な生産国があります。産地や生産者によって特徴は異なり、ナッツやチョコレートを思わせる風味から、明るい酸味を感じるものまで幅があります。

アフリカ

エチオピアやケニアなどが知られています。花や果実を思わせる香り、明るい酸味などが特徴として挙げられる豆もあります。

アジア・太平洋地域

インドネシアなどでコーヒーが生産されています。産地や精製方法によって、しっかりとしたコクや独特の風味を持つ豆もあります。

農園・地域にも注目

同じ国の豆でも、地域や農園、品種、収穫時期などによって特徴は異なります。詳しい産地情報がある場合は、豆選びの参考になります。

ここで紹介した味の傾向はあくまで目安です。産地名だけで味を決めつけず、商品に記載された風味の説明や実際に飲んだ感想も参考にしましょう。
04 / PROCESSING

精製方法による違い

精製とは、収穫したコーヒーチェリーから種子を取り出し、生豆にするまでの加工工程です。果肉などをどのように取り除くか、どのように乾燥させるかによって、豆の風味に違いが生まれることがあります。

ナチュラル

果実の状態で乾燥させた後、果肉などを取り除く方法です。果実を思わせる甘い香りや、豊かな風味が感じられる豆もあります。

ウォッシュド

果肉などを取り除き、発酵工程や水洗いを経てから乾燥させる方法です。豆によっては、すっきりとした印象や酸味の特徴が感じられます。

ハニー・パルプドナチュラル

果肉を取り除く際に粘液質の一部を残して乾燥させる方法などを指します。甘さや口当たりに特徴が出ることがあります。

そのほかの方法

地域や生産者によって、発酵の条件や乾燥方法などに工夫が加えられることもあります。精製方法の名称は商品選びの参考になります。

精製方法を見るときのポイント

精製方法は、豆の風味を想像するための手がかりの一つです。ただし、ナチュラルなら必ず甘い、ウォッシュドなら必ず酸っぱい、というように決まるわけではありません。品種や産地、焙煎度なども合わせて確認しましょう。

05 / ROASTING

焙煎度で変わる味と香り

焙煎は、生豆に熱を加えてコーヒーらしい香りや味わいを引き出す工程です。一般的に、焙煎が浅いほど酸味や豆本来の風味が感じられやすく、深いほど苦味や香ばしさが強くなる傾向があります。ただし、実際の味わいは豆の種類や焙煎方法によって変わります。

浅煎り

酸味や果実を思わせる風味が感じられやすい焙煎度です。豆の産地や品種による個性を楽しみたい人に向いている場合があります。

中煎り

酸味、甘さ、苦味のバランスが取れた味わいになることがあります。幅広いコーヒーで使われる焙煎度です。

深煎り

苦味や香ばしさ、しっかりとしたコクが感じられやすい焙煎度です。深い焙煎の風味が好きな人に選ばれます。

焙煎度はどう選ぶ？

  • 果実のような酸味や明るい風味を楽しみたいなら、浅煎りを試してみる。
  • 酸味と苦味のバランスを重視するなら、中煎りを試してみる。
  • 苦味や香ばしさを重視するなら、深煎りを試してみる。
「浅煎り・中煎り・深煎り」の区分や呼び方は、販売店や焙煎所によって異なる場合があります。商品説明に書かれた味の特徴も一緒に確認しましょう。
06 / STORAGE

コーヒー豆の保存方法と選び方

コーヒー豆は、空気、湿気、熱、光などの影響を受けます。香りをできるだけ保つためには、保存環境に気を配り、必要以上に長く置かずに使うことが大切です。

保存するときの基本

  • 直射日光を避け、温度変化の少ない場所に置く。
  • 湿気が入らないよう、袋や密閉容器をしっかり閉じる。
  • 開封後は空気に触れる時間をできるだけ減らす。
  • 一度に大量に買いすぎず、飲む量に合わせて購入する。
  • 豆の状態やパッケージに記載された保存方法も確認する。

豆を選ぶときに確認したいこと

  • 品種や産地が記載されているか。
  • 精製方法が分かるか。
  • 焙煎度や味わいの説明があるか。
  • 焙煎日や賞味期限などの表示を確認できるか。
  • 自分が好きな味の傾向に合っているか。

初めて豆を選ぶときは、すべての項目を理解している必要はありません。まずは焙煎度と味の説明を見て選び、飲んだときに感じた酸味、苦味、香りなどを覚えておくと、次の豆選びに役立ちます。

SUMMARY

このページのまとめ

コーヒー豆の特徴は、品種、産地、精製方法、焙煎度など、さまざまな要素によって変わります。どれか一つだけで味が決まるわけではありません。商品に書かれた情報を少しずつ読み取れるようになると、自分の好みに合う豆を見つけやすくなります。

次にコーヒーを買うときは、パッケージに書かれた産地や焙煎度を一つ確認してみましょう。飲んだときの感想と結びつけることが、コーヒー豆を知る第一歩です。
